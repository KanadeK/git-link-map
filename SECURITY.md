# Security

Version 0.1.x is supported. Report vulnerabilities using GitHub's private
vulnerability reporting at https://github.com/KanadeK/git-link-map/security/advisories/new.
If unavailable, open an issue requesting a private contact without disclosing
the vulnerability or private input files. Include version, platform and a
minimal synthetic reproducer when a private channel is available.

This is a local command-line tool, not a hostile-input sandbox. Run it with
ordinary user privileges on trusted local projects. Inputs and reports may
contain filenames and text supplied by you; review reports before sharing.
See README.md for the precise parsing and filesystem boundaries.
